# gen-menu

食神公式 X ([@shokujinjp](https://x.com/shokujinjp)) の直近の告知ツイートを確認し、新しいメニュー情報を CSV に追記する。

まず `AGENTS.md` を読み、データフォーマットと特記事項を把握すること。

## 1. ツイートの取得

直近 10 日分のツイートを確認する。

- X 本体は未ログインでは閲覧できない。nitter インスタンス `https://nitter.tiekoetter.com/shokujinjp` を使う
- nitter には Anubis（Proof-of-Work ボット対策）があり、curl・headless ブラウザは拒否される。**headed ブラウザを使うこと**（例: `npx agent-browser --headed`。CI では xvfb 配下で実行される前提）
- `nitter.tiekoetter.com` が落ちている場合は他の nitter インスタンスを試す
- ツイート画像は `https://pbs.twimg.com/media/<MEDIA_ID>?format=jpg&name=medium` で認証なしに直接取得できる。貼り紙は活字で鮮明なため、画像を Read で読めば OCR は不要

## 2. 対象ツイートの分類

### a. 週替わり定食の告知（毎週月曜午前に投稿）

- 「今週の週替わり定食」ツイート: メニュー貼り紙の写真 1 枚。**これが正典**。`9.<メニュー名> <価格>円 / 15.<メニュー名> <価格>円` が印字されている
- 「#食神週替わり定食」ツイート: 料理写真 3 枚（補助的に使用）
- 貼り紙に 9 番が無い週もある（その場合は 15 番のみ追記する）

### b. 期間限定・固定メニューの告知

冷やし中華・冷やし担々麺・デカ盛り企画・新メニューなど、提供期間のあるメニューの開始/終了告知。

- 開始告知から名前・価格・開始日を読み取る。開始日が明示されていなければツイート日を開始日とする
- 終了日が告知に無い場合は `limited.csv` の過去の同名メニューの期間を参考にする（例: 冷やし中華は例年 6/1〜9/30）。参考にできる過去データも無ければ**追記せず、ユーザーに報告だけする**
- 終了告知（「今年の冷やし中華は終了しました」等）を見つけた場合、既存行の `day_end` と異なれば修正を提案する

値上げ告知（全メニュー一斉の価格改定）はこのコマンドの対象外。見つけた場合は追記せずユーザーに報告する。

## 3. CSV への追記

読み取った内容を CLI に渡す。CLI が検証（月曜チェック・価格・重複）と追記を行う。CSV を直接編集しないこと。

```bash
# 週替わり（date は必ずその週の月曜日）
go -C gen_weekly run . weekly -date 2026-06-15 -name9 "豚肉と大根のピリ辛炒め" -price9 750 -name15 "鶏肉と玉ねぎのクミン炒め" -price15 880

# 期間限定
go -C gen_weekly run . limited -name "冷やし中華" -price 950 -start 2026-06-01 -end 2026-09-30 -description "冷やし中華 2026"
```

- 価格は貼り紙・告知の印字に準拠する（読み取れない場合は直近の同種メニューの価格を使い、その旨を報告する）
- `description` の表記（「週代わり」等）は CLI が既存データに合わせて付与する。limited の `description` は `<メニュー名> <年>` 形式（例: `冷やし中華 2026`）に既存データを倣う
- 既に登録済みの場合 CLI は skip と表示して正常終了する（再実行は安全）

## 4. 確認と報告

- `git diff` で追記内容を確認し、画像の読み取り結果と一致しているか検証する
- 何を追記したか（または追記すべきものが無かったか）を報告する。commit は呼び出し元（ユーザーまたは CI のプロンプト）からの明示的な指示が無い限り行わない
